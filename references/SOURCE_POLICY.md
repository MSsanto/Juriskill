# Política de Fontes

## Objetivo

Definir quando uma fonte pode ser usada para confirmar uma afirmação jurídica no Juriskill.

## Hierarquia

1. Fonte oficial primária
2. Fonte oficial secundária
3. Repositório institucional confiável
4. Doutrina ou publicação técnica identificável
5. Agregador privado
6. Conteúdo informal

Sempre que houver fonte oficial primária disponível, ela deve prevalecer sobre resumos, agregadores e reproduções de terceiros.

## Regras

- Resultado de busca não é confirmação por si só.
- Snippet de mecanismo de busca não substitui a fonte.
- Ementa não substitui inteiro teor quando a tese depende de contexto, fundamento ou delimitação do julgado.
- Reprodução de legislação em site privado não substitui texto oficial quando a vigência ou redação exata forem relevantes.
- Agregadores podem ser usados para descoberta, nunca como única confirmação quando a fonte oficial estiver acessível.
- Conteúdo do próprio modelo não é fonte.
- Documento fornecido pelo usuário pode ser usado como fonte do conteúdo que efetivamente contém, mas não comprova fatos externos que o documento apenas alegue.

## Critério de suficiência

Uma referência só pode receber status `VERIFICADA` quando a evidência disponível for suficiente para confirmar existência, identidade, conteúdo e pertinência.

Se uma dessas dimensões permanecer incerta, use `PARCIALMENTE VERIFICADA` ou `NÃO VERIFICADA`.

## Conflito entre fontes

Quando duas fontes confiáveis divergirem:

1. não escolha silenciosamente uma delas
2. registre a divergência
3. priorize a fonte de maior autoridade jurídica e maior atualidade
4. se a divergência permanecer material, não classifique como plenamente verificada

## Atualidade

Quando a validade depender de vigência, revogação, alteração legislativa, superação de entendimento ou mudança jurisprudencial, a checagem deve considerar a situação atual da fonte.

## Rastreabilidade mínima

Para cada referência material, preserve quando possível:

- identificador
- órgão ou fonte
- data de consulta
- URL ou caminho de acesso
- status de validação
- observação sobre o que foi confirmado
